*The first release of Hito: tasks, milestones and progress for your company, end-to-end encrypted, on a server you run yourself.*

> [!IMPORTANT]
> Hito está en una fase temprana (0.1): todo lo de abajo funciona y está probado contra un servidor real, pero el protocolo aún puede cambiar antes de la 1.0. Usa TLS para cualquier servidor que no esté en tu propio ordenador.

> _Hito is at an early stage (0.1): everything below works and is tested against a real server, but the protocol may still change before 1.0. Use TLS for any server outside your own computer._

## Español

### Qué incluye

- **Proyectos con hitos**: cada hito con su fecha y su progreso; se alcanza cuando su última tarea está hecha.
- **Tareas** con estado (por hacer, en curso, en revisión, hecho), prioridad, responsable, hito, fecha límite, etiquetas, descripción, lista de comprobación y comentarios.
- **Vistas**: tablero con arrastrar y soltar, lista por estado, hitos, actividad, **Mis tareas** en todos los proyectos y un **Resumen** con lo abierto, lo vencido y el progreso de cada proyecto.
- **Plantillas** para empezar un proyecto: lanzamiento de producto, proyecto para un cliente, sprint de dos semanas y evento.
- **Cifrado de extremo a extremo** con MLS (RFC 9420): títulos, descripciones, listas, etiquetas, comentarios y nombres de hitos llegan al servidor solo cifrados. [docs/security.md](https://github.com/getnodalia/hito/blob/main/docs/security.md) explica qué protege y qué no.
- **Espacios de trabajo** con invitaciones, roles e invitados que solo ven sus proyectos.
- **Integraciones**: tokens de API y webhooks firmados para conectar Hito con Ágora u otras apps, sin enviarles nunca el texto de las tareas.
- **Tiempo real**: lo que cambia un compañero aparece al momento.
- **App de escritorio nativa** para Linux, macOS y Windows con Nodalia Design (suite Office): vista Archivo con Inicio, Preferencias, atajos y Acerca de; temas claro, oscuro y de alto contraste; español e inglés; menú global por D-Bus en Linux.
- **Servidor** en un solo binario con SQLite, con paquetes para instalarlo como servicio en Linux.

## English

### What's in it

- **Projects with milestones**: each milestone with its date and progress; it is reached when its last task is done.
- **Tasks** with a status (to do, in progress, in review, done), priority, assignee, milestone, due date, labels, description, checklist and comments.
- **Views**: a board with drag and drop, a list by status, milestones, activity, **My tasks** across every project and an **Overview** of what is open, what is overdue and each project's progress.
- **Templates** to start a project: product launch, client project, two-week sprint and event.
- **End-to-end encryption** with MLS (RFC 9420): titles, descriptions, checklists, labels, comments and milestone names reach the server only as ciphertext. [docs/security.md](https://github.com/getnodalia/hito/blob/main/docs/security.md) says what it protects and what it does not.
- **Workspaces** with invitations, roles and guests who see only their projects.
- **Integrations**: API tokens and signed webhooks to connect Hito with Ágora or other apps, never sending them task text.
- **Real time**: what a teammate changes shows at once.
- **A native desktop app** for Linux, macOS and Windows in Nodalia Design (Office suite): a File view with Home, Preferences, shortcuts and About; light, dark and high-contrast themes; Spanish and English; the global menu over D-Bus on Linux.
- **A server** in one binary with SQLite, with packages that install it as a service on Linux.
