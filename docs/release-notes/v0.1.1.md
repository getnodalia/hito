Hito se actualiza solo: la app de escritorio busca e instala versiones nuevas, y el servidor se mantiene al día por su cuenta.
*Hito keeps itself up to date: the desktop app finds and installs new versions, and the server updates itself.*

## Español

### Novedades

- **Actualizaciones en la app:** Hito busca una versión nueva al arrancar y en el menú principal, **Buscar actualizaciones…**. Descarga con reanudación si la conexión se corta y la instala con un clic.
- **El servidor se actualiza solo:** `hito-server self-update` instala la última versión estable, comprobada contra `SHA256SUMS`, con una copia de la base de datos en `backups/` antes de tocar nada y marcha atrás si el servidor no arranca. Los paquetes activan un temporizador diario de systemd; `[updates] automatic = false` en `hito.toml` lo desactiva.

## English

### What's new

- **Updates in the app:** Hito looks for a new version at start and from the main menu, **Check for updates…**. The download resumes if the connection drops, and one click installs it.
- **The server updates itself:** `hito-server self-update` installs the latest stable release, checked against `SHA256SUMS`, with a database snapshot in `backups/` before anything changes and a rollback if the server does not come back. The packages enable a daily systemd timer; `[updates] automatic = false` in `hito.toml` turns it off.
