# Security policy

Please report a vulnerability in Hito privately through
[GitHub private vulnerability reporting](https://github.com/getnodalia/hito/security/advisories/new),
not in a public issue or pull request. Say which version you ran, on which platform, and how to
reproduce the problem.

Nodalia maintains Hito and handles every report. Only the latest release receives security fixes.

Nothing has been released yet; until the first release, fixes land on `main`. The security model,
what Hito protects and what it does not, is in [docs/security.md](docs/security.md).
